## Companies and platforms

**Agentic builders — describe what you want, it builds it**

| Name | In one line |
| --- | --- |
| [Replit](https://replit.com/) | A full development environment in the browser, with an AI agent that writes and hosts the app |
| [Lovable](https://lovable.dev/) | Describe an app in chat; it builds and deploys it |
| [Bolt](https://bolt.new/) | Same idea, from StackBlitz, who pioneered running dev tools in a browser tab |
| [v0](https://v0.app/) | Vercel's tool for generating user interfaces from a description |
| [Base44](https://base44.com/) | Vibe-coding platform for apps and websites |
| [Mocha](https://getmocha.com/), [Woz](https://www.withwoz.com), [Rocket](https://www.rocket.new/) | Newer entrants doing the same thing |
| [PartyKit](https://www.partykit.io/) | Makes any app realtime and multiplayer |

## Open-source projects and command-line tools

| Project | In plain terms | How widely used |
| --- | --- | --- |
| [Agent Skills](https://agentskills.io/) | A single markdown file that teaches an AI assistant how to do a specific task | An emerging open format; roughly a year old |
| [Prisma](https://www.prisma.io/) | Defines your database structure in one file and generates the code to read and write it | The most widely used ORM in TypeScript |
| [Drizzle](https://orm.drizzle.team/) | A lighter, newer alternative to Prisma | Fast-growing in the last two years |
| [SQLAlchemy](https://www.sqlalchemy.org/) | The equivalent for Python | The long-standing standard in Python |
| [libSQL](https://turso.tech/libsql) | A complete database kept inside a single ordinary file | An open fork of SQLite — itself the most deployed database in the world, in every phone, browser and car |
| [ffmpeg](https://ffmpeg.org/) | Converts and processes essentially any video or audio format | Sits inside most video products you have ever used |
| [curl](https://curl.se/) | Fetches data from a web address | Ships on billions of devices |
| [Jujutsu](https://jj-vcs.github.io/jj/) | A newer version-control system, compatible with Git repositories | Young, actively developed, growing fast |
| [OpenSSL](https://openssl-library.org/) | Encryption that secures connections | Underpins a large share of the secure web |
| [ImageMagick](https://imagemagick.org/) | Converts and edits images at scale | A standard building block in publishing pipelines |
| [Tesseract](https://tesseract-ocr.github.io/) | Reads text out of photographs and scans | The default open-source OCR engine |
| [Pandoc](https://pandoc.org/) | Converts documents between Word, PDF, Markdown and HTML | The standard tool for document conversion |
| [Ollama](https://ollama.com/) | Runs AI language models on your own computer | The common way to run models locally |
| [ripgrep](https://github.com/BurntSushi/ripgrep) | Searches text across thousands of files instantly | Built into many editors, including VS Code |
| [fzf](https://junegunn.github.io/fzf/) | Type a few letters and it finds the file you meant | One of the most-installed terminal tools |
| [ExifTool](https://exiftool.org/) | Reads and edits hidden metadata inside photos and files | The reference tool for photo metadata |
| [eza](https://eza.rocks/) | Lists the contents of a folder, with colour and detail | A modern replacement for a command every developer runs daily |
| [Zellij](https://zellij.dev/) | Splits one terminal window into many working panes | Growing replacement for tmux |
| [Yazi](https://yazi-rs.github.io/), Superfile | Browse and manage files inside the terminal, very fast | Popular in the terminal-first community |
| [Helix](https://helix-editor.com/), [Neovim](https://neovim.io/) | Keyboard-driven text editors | Used daily by professional developers |
| [Atuin](https://atuin.sh/) | Makes your command history searchable across machines | Widely adopted in the last two years |
| [tldr](https://tldr.sh/) | Plain-English cheat sheets for command-line tools | The common answer to "how do I use this again" |
| [Podman](https://podman.io/) | Runs software in isolated containers | The main open alternative to Docker |
| [GnuPG](https://gnupg.org/) | Encrypts files and signs software releases | The standard for verifying software authenticity |
